# Product Overview

Open Event is an open-source event management platform that connects three key stakeholders in the event ecosystem:

## Core Users

- **Organizers**: Create and manage events with AI assistance, track budgets, coordinate vendors, and find sponsors
- **Vendors**: Service providers (catering, AV, photography, security, etc.) who showcase services and get hired
- **Sponsors**: Companies looking to support events and manage sponsorship investments

## Key Features

- **AI Event Assistant**: Natural language event creation with 13 integrated tools and confirmation dialogs
- **Event Dashboard**: Real-time analytics, task management (Kanban-style), and budget tracking
- **Vendor/Sponsor Discovery**: AI-powered matching and recommendations with verification system
- **Progressive Web App**: Works offline, installable on any device, push notifications ready

## Event Workflow

Events follow a status progression: `Draft` → `Planning` → `Active` → `Completed`

## AI Agent System

The platform features an intelligent AI assistant powered by OpenAI GPT-4o-mini with function calling capabilities. The agent can create events, find vendors, discover sponsors, and manage event operations through natural conversation with user confirmation for important actions.

## Business Model

Open-source MIT licensed platform with multi-tenancy support for organizations and subscription plans (free, pro, business, enterprise).
