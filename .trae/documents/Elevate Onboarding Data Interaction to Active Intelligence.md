### **The Problem**
The current implementation of how "Answer" data interacts with the system is functional but **passive and reactive**. It acts largely as a static record that is occasionally read for display or gating. It lacks **proactive intelligence** and deep integration.

### **The Solution: Intelligent, Proactive, and Deeply Integrated**
I will transform the functional scenarios into a system where the onboarding data actively *drives* the platform experience, rather than just sitting in a database.

### **Key Improvements**

1.  **AI-Driven Dashboard (Smart Feed)**:
    *   *Current*: Static list of generic tips.
    *   *Improved*: A dynamic "Action Feed" generated by the AI agent upon login, using the `getUserProfile` tool to prioritize tasks (e.g., "Since you're a first-time organizer, here's a checklist for venue scouting").

2.  **Context-Aware Navigation**:
    *   *Current*: Standard sidebar for everyone.
    *   *Improved*: Adaptive navigation that highlights relevant tools. If `role` is "Sponsor", hide "Venue Management" and highlight "Sponsorship Opportunities".

3.  **Proactive Resource Matching**:
    *   *Current*: User must search for vendors manually.
    *   *Improved*: The system automatically runs a background job (via Convex scheduler) to match the user's `eventTypes` and `goals` with top-rated vendors in the marketplace, presenting a "Recommended for You" list on Day 1.

4.  **Lifecycle-Based Nudging**:
    *   *Current*: No specific lifecycle management beyond initial onboarding.
    *   *Improved*: A "Profile Health" monitor that prompts users to update their goals if they haven't changed in 6 months, ensuring the AI context remains fresh.
